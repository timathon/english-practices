App Development Plan

A phased engineering roadmap for building 知新堂 (Zhī Xīn Táng) and its flagship Chinese Poetry module 白莲阁 (Bái Lián Gé) (inspired by 白居易《池上》 "小娃撑小艇，偷采白莲回") — featuring hierarchical account provisioning, Cloudflare edge backend, and WeChat Mini Program exportability.

🔑 Account & Password

Admin sets up Teachers; Teachers setup Parents & Students. Zero public self-reg.

🌐 Web SPA Target

Primary desktop, tablet & mobile web application built with React + Vite.

📦 WeChat Exportable

Taro / Uni-App architecture preserving full exportability to WeChat Mini Program.

⚡ Cloudflare Backend

Cloudflare Workers, D1 SQLite, KV cache, R2 storage & AI Gateway.

0. Executive Development Strategy

Development is structured into 5 iterative phases over 20 weeks. The architecture prioritizes rapid web deployment first, while strictly adhering to Taro/Uni-App component boundaries so the entire codebase can be compiled into a native WeChat Mini Program (微信小程序) target without rewriting UI components or state logic.

🚫 Scope Boundary: Native iOS and Android application builds are explicitly excluded from the roadmap to focus engineering energy on a high-performing Web SPA and WeChat Mini Program exportability.
Phase 1 • Weeks 1–4

Foundational Architecture & Account Provisioning Engine

🏗️

Key Engineering Deliverables:

  • ✓ Cloudflare Worker & D1 Setup: Initialize D1 SQLite database with tables for users, roles, classes, poems, and assignments.
  • ✓ Hierarchical Account Auth API: Implement account/password login endpoints (POST /api/auth/login) supporting bcrypt hash validation.
  • ✓ Admin Provisioning Portal: Admin view for setting up Teacher accounts & assigning class permissions.
  • ✓ Teacher Roster Builder: Teacher UI to generate batch Student & Parent account IDs and initial passwords.
Auth Endpoint Contracts (Phase 1) 
// Admin -> Provision Teacher Account
POST /api/admin/teachers
Body: { "name": "Ms. Zhang", "email": "zhang@school.edu", "temp_password": "..." }

// Teacher -> Batch Provision Student Accounts
POST /api/teacher/class/provision
Body: { "class_name": "Class 3A", "students": ["Emma", "Lucas", "Yaming"] }
// Returns: Array of { username, account_id, initial_password }
Phase 2 • Weeks 5–8

Flagship Module "白莲阁" & Core Quiz Runner

🪷

Key Engineering Deliverables:

  • ✓ 100-Poem Foundation Schema: Structure JSON data for Tang/Song classics including text, Pinyin, keywords, and audio URLs.
  • ✓ Landscape Map Navigation: Responsive watercolor landscape map with glowing poem node states and flag markers.
  • ✓ Interactive Quiz Engine: Full-screen quiz runner supporting Cloze, Scrambled Verse Assembly, and Picture-Line matching.
  • ✓ Mythical Scroll Garden: Radical (部首) and beast fragment unlock system triggered by quiz completion.
  • ✓ Semantic Ruby Pinyin Renderer: Native HTML5 <ruby> rendering with dynamic toggle logic.
Quiz Types Built in Phase 2:
Type 1: Scrambled Verse Drag/Tap — Student reorders scrambled character blocks to form correct line.
Type 2: Target Character Cloze — Select correct missing character among 4 distractor options.
Type 3: Image Scene Match — Match watercolor scene art to corresponding poem line.
Phase 3 • Weeks 9–12

Invisible AI Coach & Spaced Repetition (SRS) Engine

🤖

Key Engineering Deliverables:

  • ✓ Cloudflare AI Gateway Proxy: Proxy LLM requests for prompt caching, token usage tracking, and rate limiting.
  • ✓ SM-2 Spaced Repetition Algorithm: Calculate individual retention curves and inject review nodes into daily maps.
  • ✓ Real-Time Adaptive Flow: Automatically hide Pinyin after 5 correct answers; inject picture clues upon 2 consecutive errors.
  • ✓ Teacher & Parent AI Briefings: Generate plain-language executive summaries for teachers and bedtime story suggestions for parents.
SM-2 Spaced Repetition Formula

I(1) = 1 day, I(2) = 6 days, I(n) = I(n-1) * EF
EF' = EF + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02))

Automatically reschedules reviewed poems right before forgetting occurs based on student answer latency and confidence score.
Phase 4 • Weeks 13–16

Teacher Portal, PDF Worksheet Engine & Live Classroom Mode

🏫

Key Engineering Deliverables:

  • ✓ 30-Sec Assignment Creator: Teacher UI to pick poems, set due dates, and assign to specific class rosters.
  • ✓ Client-Side PDF Generator: Export high-res printable paper worksheets formatted with character stroke grids and Pinyin lines.
  • ✓ Live Classroom Sync Engine: WebSocket / Cloudflare Durable Objects for real-time live polling and smartboard display.
Live Classroom Sync Flow

1. Teacher starts session → Generates 4-character Class Code (e.g. #9842).

2. Students enter code → Joined state synced via Cloudflare Durable Objects.

3. Teacher pushes Question 1 → Instant real-time submission count chart on smartboard.

Phase 5 • Weeks 17–20

WeChat Mini Program Export & Pilot School Launch

🚀

Key Engineering Deliverables:

  • ✓ WeChat Cross-Compilation: Execute Taro / Uni-App build command to export native WeChat Mini Program bundle (.wxml / .wxss).
  • ✓ Cloudflare Mainland Edge Tuning: CDN route optimization for low-latency asset delivery inside Mainland China.
  • ✓ School Pilot Program: Onboard 5 partner school classrooms using teacher-provisioned account rosters.
WeChat Build Export Command: npm run build:weapp

Compiles Web SPA React components into WeChat Mini Program format for WeChat DevTools deployment.

Technical Stack Specification

Frontend Framework React / Vite SPA with Taro or Uni-App wrapper for WeChat Mini Program exportability.
Edge Serverless API Cloudflare Workers & Cloudflare Pages Functions running serverless JS at the edge.
Database & Storage Cloudflare D1 (Serverless SQLite), KV Cache for sessions, R2 Object Storage for audio/art assets.
AI Infrastructure Cloudflare AI Gateway caching LLM API requests for the Invisible AI Coach engine.
