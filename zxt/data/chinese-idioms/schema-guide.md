# 知新堂 (ZXT) - 成语接龙 900 (幼小衔接) Dataset Standard & Schema Guide

本文档定义了知新堂（ZXT）**成语接龙 900（幼小衔接版）** 数据集的组织规范、题目类型定义、JSON Schema 结构与干扰项设计标准。

---

## 1. 认知特点与设计原则 (Pedagogical Principles for 幼小衔接)

1. **拼音与图像强辅助 (Pinyin & Visual Anchors)**：面向 5~7 岁幼小衔接儿童，成语、生字、故事正文均需配备完整标准汉语拼音（带声调），关键故事配备卡通/国风场景插图。
2. **字音字形防混淆 (Phonetic & Graphic Discrimination)**：着重考查常见易错字、形近字、同音字（如：*神采飞[扬]* vs *[阳/洋]*，*叶公好[龙]* vs *[笼/庞]*）。
3. **首尾接龙心智模型 (Solitaire Chain Building)**：基于教材第 1 页接龙路径，引导儿童掌握“前词末字 = 后词首字”的衔接规律。
4. **生活情境与故事启蒙 (Situational & Story-driven Comprehension)**：避免生硬文言训诂，聚焦于生活情境选择、情绪表情匹配与成语寓言故事理解。

---

## 2. 组数据结构规范 (`zxt/data/chinese-idioms/idoms/group-{id}.json`)

每组对应教材的一个 **4 页模块化单元**（共 33 组，每组 16 个成语 + 综合练习题）：

```json
{
  "id": 1,
  "group_number": 1,
  "title": "成语接龙第1组",
  "idioms": [
    {
      "index": 1,
      "word": "一字千金",
      "pinyin": "yī zì qiān jīn",
      "partial_meanings": "",
      "full_meaning": "原指文辞精妙，不需要修改。后来形容文学作品或书法作品等价值极高。",
      "has_story": true
    },
    {
      "index": 5,
      "word": "神采飞扬",
      "pinyin": "shén cǎi fēi yáng",
      "partial_meanings": "神采：人的精神、神气和光彩。",
      "full_meaning": "形容人精神饱满的样子。",
      "has_story": false
    },
    {
      "index": 6,
      "word": "扬眉吐气",
      "pinyin": "yáng méi tǔ qì",
      "partial_meanings": "",
      "full_meaning": "扬起眉头，吐出怨气。形容摆脱压抑心情后高兴、痛快的样子。",
      "has_story": false
    }
  ],
  "questions": [...]
}
```

- `partial_meanings`：字词级拆解与特指词语注解（若无特指字词拆解则留空字符串 `""`）。
- `full_meaning`：成语整体白话完整释义与比喻义。

## 3. 成语题型定义 (`questions` 数组)

所有题目必须包含唯一的 `id` (字符串) 与 `type` 字段。

### 3.1 已有题型 (当前正选与主推题型)

#### 3.1.1 `IdiomAssembly` (成语还原)
将打乱的字块拼接成正确的四字成语。
- **题干引导与防剧透规则**：
  - 前端题干固定为：`请根据成语释义，点击字块拼接出对应的四字成语：`。
  - **释义提示（Hint）**：系统自动读取对应成语的 `full_meaning`（完整比喻义），**严禁包含 `partial_meanings`（字词拆解）与拼音**，防止如“龙马：古代骏马”直接泄露“龙”、“马”等成语关键字。
- **干扰字规则**：每个题目必须提供 **恰好 3 个** `distractor_chars`：
  - **1 个语义陷阱字**（如“风”构成“风采”混淆“神采”）；
  - **2 个成语中不同字的同音字陷阱**（如“彩”混淆“采”，“扬”混淆“扬”）。

```json
{
  "id": "q_idm_001_assembly_1",
  "type": "IdiomAssembly",
  "answer": "神采飞扬",
  "distractor_chars": ["风", "彩", "杨"]
}
```
> **干扰项设计解析**：`风` 为“风采”混淆“神采”的语义陷阱；`彩` 为“采”的同音字陷阱；`杨` 为“扬”的同音字陷阱。作答时释义仅呈现 `full_meaning`: *“形容人精神饱满的样子。”*

---

#### 3.1.2 `ChainAssembly` (接龙还原)
考查连续 3 个首尾衔接成语的链条还原能力。保留成语的首尾字作为锚点，挖去每个成语的中间两个字（共 6 个待填字），并提供 **3 个干扰字**（字池共 9 个字供学生选择填空）。

- **题目结构与规则**：
  - `idioms`: 必须为连续首尾相接的 **3 个成语**（如 `["一字千金", "金枝玉叶", "叶公好龙"]`）。
  - `distractor_chars`: **恰好 3 个干扰字**。建议优先从这 3 个成语对应的 `IdiomAssembly` 题目的干扰字池中各选取 1 个具有高混淆度的形近字/同音字/语义字（如 `["万", "支", "工"]`）。
  - `prompt`: 题目引导提示语（可选，默认：`成语接龙链条还原：请点击下方字块，将接龙成语中间缺漏的汉字填入正确位置：`）。
- **学生界面交互与展示**：
  - 接龙成语展示为：`一 [ _ ] [ _ ] 金 ➡️ 金 [ _ ] [ _ ] 叶 ➡️ 叶 [ _ ] [ _ ] 龙`
  - 候选字块池（共 9 字打乱）：`字`、`千`、`枝`、`玉`、`公`、`好` + 3 个干扰字 `万`、`支`、`工`。
  - 学生依次点击字块填入对应的空位槽，支持点击已填槽位退回字块。

```json
{
  "id": "q_idm_001_chain_1",
  "type": "ChainAssembly",
  "idioms": [
    "一字千金",
    "金枝玉叶",
    "叶公好龙"
  ],
  "distractor_chars": [
    "万",
    "支",
    "工"
  ]
}
```

#### 3.1.7 `TyposSpotting` (错别字辨析 / 火眼金睛)
考查成语字形书写准确度。题干为多项选择题，每个选项包含 **3 个成语**（用顿号 `、` 连缀）：
- **本组闭环取材原则 (Current Group Vocabulary Only)**：每个选项中的所有成语（无论正确与否）**必须全部取材于当前组（本单元 16 个成语）**，严禁引入未学过的超纲或外部成语，以确保紧扣当堂教学重点。
- **打乱接龙顺序原则 (Non-sequential Idiom Combination)**：每个选项内的 3 个成语**严禁按相邻接龙顺序排列**（如不应直接连成“一字千金、金枝玉叶、叶公好龙”），应从本组 16 个成语中跨序离散挑选组合（如“一字千金、怒目而视、叶公好龙”），彻底消除接龙顺序带来的联想提示，纯粹考查字形辨析。
- **题目内成语不重合原则 (No Same-Idiom Repetition/Comparison in Same Question)**：**同一道题目的 4 个选项中，不得出现同一个成语的不同变体或重复**（例如：严禁在选项 A 出现错字版“马革裹师”，又在选项 D 出现正字版“马革裹尸”泄露答案）。每道题目内 4 个选项涉及的成语应当各自独立，覆盖不同词条。
- **1 个正确选项**：所含的 3 个成语字形完全正确无误（均为本组成语）。
- **3 个干扰选项**：每项均包含 1 个含错别字/同音形近陷阱字的本组成语（如“针**峰**相对”应为“针**锋**相对”、“神采飞**阳**”应为“神采飞**扬**”、“金**支**玉叶”应为“金**枝**玉叶”）。
- **错词位置随机化规则 (Randomized Typo Position)**：在 3 个干扰选项中，**含有错别字的成语在 3 个成语序列中的位置必须随机分布**（即错词可出现在第 1、第 2 或第 3 个位置，严禁固定在首位），以确保学生认真核验整组词语。
- **答案随机化**：正确选项在 `options` 列表中的索引位置（0~3）需随机分布。

```json
{
  "id": "q_idm_001_typos_1",
  "type": "TyposSpotting",
  "prompt": "下列四组词语中，【成语字形完全正确】的一组是：",
  "options": [
    "气象万千、神采飞阳、见缝插针",
    "一字千金、怒目而视、叶公好龙",
    "视而不见、千军万马、真锋相对",
    "尸横遍野、金枝玉叶、龙马精伸"
  ],
  "answer": 1,
  "explanation": "B项字形全部正确；A项‘神采飞阳’应为‘神采飞扬’（错在第2个）；C项‘真锋相对’应为‘针锋相对’（错在第3个）；D项‘龙马精伸’应为‘龙马精神’（错在第3个）。"
}
```

### 3.2 备选题型 (备用题型库)

#### 3.2.1 `IdiomCloze` (成语缺字填空)
成语中挖去 1 个字，提供 4 个包含同音、形近或同义陷阱的选项。

```json
{
  "id": "q_idm_001_cloze_1",
  "type": "IdiomCloze",
  "prompt": "叶公好____ (yè gōng hào lóng)",
  "options": ["龙", "笼", "尤", "庞"],
  "answer": 0,
  "explanation": "‘叶公好龙’中的‘龙’指神话传说中的神龙，不是竹笼的‘笼’。"
}
```

---

判断成语所表达的情绪、褒贬色彩或生动神态，适合低龄儿童进行情感联结。

```json
{
  "id": "q_idm_001_emotion_1",
  "type": "EmotionMatch",
  "prompt": "成语“勃然大怒”和“怒目而视”表达的是下面哪种情绪？",
  "options": [
    "😡 生气发怒",
    "😄 开心欢喜",
    "😭 伤心难过",
    "😴 困倦疲劳"
  ],
  "answer": 0,
  "explanation": "‘勃然大怒’和‘怒目而视’都与发脾气、极度生气有关。"
}
```

## 4. 干扰项设计规范 (Distractor Quality Standards)

为了保证幼小衔接练习的区分度与教学效果，干扰项需严格遵守以下标准：

1. **同音/近音字陷阱**：优先采用拼音相同或声调相近的常见字（如：*扬/洋/阳/样*，*金/今/巾/斤*，*龙/笼/隆*）。
2. **形近字陷阱**：选用字形骨架相近、易混淆偏旁的汉字（如：*龙/尤/庞*，*视/见/现*，*针/钉/钩*）。
3. **词性与结构对仗**：多项选择题中，干扰成语应与目标成语具备相同字数与相近结构（如四字成语对四字成语）。
4. **排除常识冲突与歧义**：避免使用意思模糊或双重正解的选项，解析须用浅显生动的儿童化语言解释。
