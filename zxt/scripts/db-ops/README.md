# ZXT Database Operations & Bug Fix Documentation

This directory documents the database operations, troubleshooting steps, and fixes applied to resolve duplicate quiz records and timestamp offset issues in **ZXT (智学堂)**.

---

## 1. Problem Overview

### Issue A: Duplicate Quiz Records
- **Symptom**: When students completed a quiz and clicked **"完成并退出"**, multiple identical quiz history records were saved to the database (e.g. 5–6 records created within seconds).
- **Root Cause**:
  1. `onClose` in `BaiLianGe.tsx` was `async` and only cleared the modal (`setActiveStudentQuiz(null)`) *after* network requests finished.
  2. The **"完成并退出"** button in `StudentQuizPreviewModal.tsx` did not disable itself or prevent subsequent clicks while waiting.
  3. The user clicked the button multiple times thinking the app was un-responsive, triggering parallel requests to `apiService.markAssignmentCompleted` and `apiService.recordQuizResult`.

### Issue B: 8-Hour Ahead Record Timestamps
- **Symptom**: Quiz records taken at local time `16:01:34` displayed as `00:01:34` (the next day, 8 hours ahead).
- **Root Cause**:
  - Timestamps stored in local storage or D1 DB are formatted local time strings without timezone indicators (e.g. `2026/7/31 16:01:34`).
  - `formatLocalTime` in `api.ts` was appending `Z` (`2026-07-31T16:01:34Z`) to strings without timezone markers.
  - Specifying `Z` forced JS Date parsers to treat `16:01:34` as UTC time. Converting this to the browser's local timezone (UTC+8 in China) added +8 hours, shifting `16:01:34` to `00:01:34` (next day).

## 2. Codebase Fixes Applied

### 1. Fix Time Parsing (`api.ts` & `StudentQuizHistoryTab.tsx`)
- Added a `parseDate` helper in `api.ts` that detects whether a timestamp includes timezone markers (`Z` or `+`).
- For local time strings without timezone offset, it converts spaces to `T` *without* appending `Z` (`2026-07-31T16:01:34`). JS parses this natively as local time.

```ts
export function parseDate(timeStr?: string): Date | null {
  if (!timeStr) return null;
  let dateStr = timeStr.trim();
  if (dateStr.includes('/')) {
    dateStr = dateStr.replace(/\//g, '-');
  }
  if (!dateStr.includes('Z') && !dateStr.includes('+')) {
    const parts = dateStr.split(' ');
    if (parts.length === 2) {
      const [dPart, tPart] = parts;
      const dSub = dPart.split('-').map(p => p.padStart(2, '0')).join('-');
      dateStr = `${dSub}T${tPart}`;
    }
  }
  const d = new Date(dateStr);
  return isNaN(d.getTime()) ? null : d;
}
```

### 2. Immediate Modal Dismissal & Button Lock (`StudentQuizPreviewModal.tsx` & `BaiLianGe.tsx`)
- Introduced `isSubmitted` state in `StudentQuizPreviewModal.tsx` to immediately lock the button and display `⏳ 正在退出...` on the first click.
- Updated `onClose` in `BaiLianGe.tsx` to immediately clear `activeStudentQuiz` and execute API requests asynchronously in the background.
