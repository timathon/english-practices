# Writing Task

<!-- col -->
### 写作情景
随着时代的发展，我们的生活发生了巨大的变化。请以 "Changes in My Life" 为题，写一篇短文描述自进入初中以来，你的生活发生了哪些变化（例如学校、居住环境、学习方式等），并说明保持不变的是什么。

<!-- col -->
### 对比维度参考
| 维度 (Aspect) | 过去 (Past) | 现在 (Present) |
| :--- | :--- | :--- |
| **学校 / 交通** | 走路上学 / 离家近 | 乘公交上学 / 离家较远 |
| **居住环境** | 住在小公寓 / 空间窄 | 搬进大房子 / 与祖辈同住 |
| **学习方式** | 独自被动学习 | 小组合作讨论 / 自信表达 |
| **保持不变** | 家庭的温暖与关爱 | 始终不变的爱与幸福 |

<!-- col -->
### 写作要求
1. 包含表格中至少两个维度的变化，并点明一项不变的情感或品质；
2. 恰当运用一般过去时和现在完成时进行对比；
3. 语句通顺，逻辑清晰，行文连贯；
4. 词数不少于80词。

> Now that I am in junior high school, my life has changed a lot compared with my primary school days...
