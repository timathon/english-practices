## 1. 经典印欧/拉丁/希腊核心词根 (Classical Roots)

### act (行动，做，扮演；驱使)
> **源义:** 拉丁语 *agere / actus* (做，驱使，行动)

* 16. **act** `v.` (1) 行动；(2) 扮演(戏剧、电影中的角色) `n.` (1) (戏剧、歌剧等的)一幕；(2) 行为
* 17. **action** `n.` (1) 行动；(2) 行为 *(act + -ion 动作/行为)*
* 18. **active** `adj.` (1) 积极的；(2) 活跃的 *(act + -ive 倾向于行动的)*
* 19. **activity** `n.` (`pl.` activities) 活动 *(active + -ity 性质/状态)*
* 20. **actor** `n.` (男)演员 *(act + -or 人)*
* 21. **actually** `adv.` 的确；真实地；事实上；实际上 *(actual 实际的 + -ly)*

### dict / dic (说，言，声明)
> **源义:** 拉丁语 *dicere / dictus* (说，宣布)

* 534. **dictionary** `n.` 词典；字典 *(dict + -ion + -ary 记录说话词汇的书)*
* 1595. **predict** `v.` 预言 *(pre- 提前 + dict 说 → 预先说出)*

---

### port (搬运，携带，运送)
> **源义:** 拉丁语 *portare* (运送，拿)

* 1572. **polite** `adj.` 有礼貌的；客气的 *(衍生修养概念)*
* 1740. **reporter** `n.` 记者，通讯员 *(re- 回 + port 携带/汇报 + -er 人 → 汇报信息的人)*
* 2210. **transport** `n.` 交通运输系统 `v.` 运输，运送 *(trans- 穿过 + port 运送)*

### vid / vis (看见，观看)
> **源义:** 拉丁语 *videre / visus* (看)

* 5. **advice** `n.` [U] 建议；忠告；劝告 *(ad- 到 + vic/vis 看法 → 给予指引)*
* 31. **advise** `v.` 劝告；忠告；建议 *(advice 的动词形式)*
* 1063. **interview** `n. & v.` 面试；采访 *(inter- 相互 + view 看 → 面对面交谈)*
* 1765. **review** `n.` 回顾，审查，评论 `v.` 回顾，温习，复习，重新考虑 *(re- 再次 + view 看)*
* 2132. **television** `n.` 电视 *(tele- 远程 + vis 看 + -ion)*
* 2315. **vision** `n.` 视力；视觉；远见 *(vis + -ion)*
* 2316. **visit** `v.` 拜访；访问；参观 `n.` 拜访；访问 *(vis + -it 走去看)*
* 2317. **visitor** `n.` 访问者；参观者 *(visit + -or 人)*
